FAQ

Click a question to expand

Is my code sent anywhere?+
No. soloknuckle runs 100% locally — checks execute on your machine against your files, and nothing is uploaded, logged or phoned home. Zero telemetry is a hard design rule, not a setting you can accidentally flip.
I'm a solo dev. Isn't this overkill?+
Solo devs are actually the biggest user group (61% of installs). You review the most per capita and have the least time for it. One install replaces hours of hand-writing rules files — and it keeps working as you switch agents and stacks.
Which AI agents and editors are supported?+
Claude Code, Cursor, GitHub Copilot, Aider and any MCP-capable tool out of the box. Anything else works through plain pre-commit hooks and shell scripts — the guardrails live in your repo, not inside one vendor's plugin system.
Will it slow my agent down?+
Median check time is ~3 seconds, and most checks run only on changed files. Compare that to the 45 minutes you'd spend unpicking a bad agent edit — it pays for itself the first time it blocks a secret leak or an out-of-scope rewrite.
Can I use it on private repos and at work?+
Yes. It's ISC licensed with no accounts, no seats and no phone-home, so there's nothing for your security team to object to. The config file commits into your repo, so the whole team inherits the same guardrails automatically.
What if I already have rules files / pre-commit hooks?+
They coexist fine. soloknuckle doesn't replace your existing hooks or editor rules — it adds runtime enforcement on top. The installer detects what you already have and wires around it instead of over it.
How do I uninstall it?+
One command, zero residue: npm uninstall -g soloknuckle and delete the .sk/ folder. No daemons, no background processes, nothing hiding in your shell profile.
Is it really free?+
Yes — ISC licensed, every feature, forever. If it saves you one bad Friday, buy the maintainer a coffee. That's the entire business model.
